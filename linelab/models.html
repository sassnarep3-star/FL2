Model comparison

The adjusted model is the one this project set out to test. The unadjusted model is the control a reader would build in a spreadsheet. Both are scored on the same proper score, on the same games, against a benchmark measured only on the training window.

Result: adjustment did not help. On the holdout moneyline the control scores +0.0686 and the adjusted model +0.0112. On the side, both lose; on the total, both lose by less. The honest conclusion is that the opponent-adjusted scoring model in this repository does not carry information the naive season average lacks — which is the same conclusion every previous section of this repository reached by a different route.

Proper score, uncertainty and multiplicity

Brier skill score = 1 − (model Brier ÷ benchmark Brier), where the benchmark is the base rate measured on 1999–2015 only. The interval is a 2,000-resample bootstrap clustered on games. The last column is a Bonferroni–Holm adjustment across every hypothesis tested here, so a lucky result among many is not reported as discovery.

A correction this project had to make. The received wisdom is that a high-scoring game has a larger winning margin, which would make a side-and-total same-game parlay invalid to price by multiplication. On ('7088', 'n') games that relationship is close to zero and its interval contains zero. The multiplication rule in this project therefore rests on same-team and same-player dependence, which has not been measured here, and the site says so rather than borrowing the conventional claim.

Control baselines

A coin flip scores a Brier skill of about zero by construction. A model that cannot beat it is noise. The always-home and always-favourite cover rates are published beside every model for the same reason.
