Everything a reader should not take on trust, with the source that shows the problem and what would resolve it. None of these blocks the site; all of them should be read before any number here is used in a decision.

Two of these are corrections of this project's own earlier claims — a correlation that was assumed and turned out to be near zero, and a model that was expected to beat its control and did not. They are listed here rather than quietly fixed, because a project that only flags other people's errors is not being honest.
