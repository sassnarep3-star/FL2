Suggestions, for review before anything is built

These are proposals, not changes. Each names the problem, the options, and a recommendation, so a reviewer can pick a path before work starts rather than after. Nothing on this page has been implemented.

How to use this page. Mark a decision beside each proposal. The recommended path is the one the evidence on this site supports; the alternatives are listed because several of them are cheaper and one of them is free.

Not betting advice. This is a measurement project. Every value is either reproducible from a committed file in this repository or left blank; blanks are listed on Flagged. Model prices come from nflverse/nfldata, an open mirror of published official results and market numbers; availability comes from nfl.com.
