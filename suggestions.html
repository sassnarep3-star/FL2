Suggestions

Improvement proposals, organized so a reviewer can examine each one and choose the best path before any change is implemented. Nothing here is an instruction to implement — each suggestion must be reviewed, a path chosen, and the decision recorded in the decision log below. Suggestions are ordered by decision priority.

How the review process works

  1. Review — read each suggestion, its options, and the question it resolves (linked from Questions & Answers).
  2. Verify what you can — check any factual claims against the linked official sources before deciding.
  3. Choose a path — accept, reject, or modify. For each suggestion record the chosen option and the reason.
  4. Record before implementing — write the decision in the decision log below (or its GitHub location per S13), then implement. Unreviewed suggestions stay Pending review.
