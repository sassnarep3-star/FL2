Verification Method

How every value on this site was verified, and the rules that keep it honest. Verification performed 2026-11-14.

1. Rules

  • Official sources only. Data values are taken only from official sources — the NFL's own pages (nfl.com) and official team websites. Third-party aggregators are not used for verified values (see irregularity F3).
  • Every table row carries a source link to the official page where its value was verified. Machine-readable records live in data/verified/*.json.
  • Never infer. If a value cannot be confirmed from an official source, it is left blank and flagged on Flagged for Review.
  • Design vs. fact. Strategy designs, gate proposals, questions, and suggestions are labeled as project proposals, not claims of external fact. Where a proposal references a fact, the fact is sourced.
  • Timestamps. Every verified data set is stamped with its verification date so staleness is visible.

3. Verification process

  1. Fetch the official page directly (each URL above was fetched and parsed in full).
  2. Extract values line by line — no values copied from third-party summaries.
  3. Record each verified value in the canonical JSON under data/verified/ with its source link.
  4. Render the site tables from those records, so each row inherits its source link.
  5. Flag anything unconfirmable — left blank and listed on Flagged for Review.
  6. Log every fetch, its result, and any irregularity in the fetch log: fl2-dashboard/data/verified/fetch-log.md.

4. Verification scope & limitations

  • Verified data covers the 2026 season snapshot as of 2026-11-14 (Week 10). It will go stale as the season progresses — refresh rules are proposed in Suggestions S14.
  • Injury reports reflect designations at verification time; final game statuses are determined on game days and are re-verified when refreshed.
  • Lines, odds, correlation values, and gate thresholds are intentionally absent until their decision questions are answered — absence is a flagged gap, not an omission.
  • No claim on this site has been marked verified without a check against an official source with a link on the page.
