How to use this page. One row is one decision, not one file: entries that describe the same work in different registers are merged into a single row and every originating id is kept underneath it, so nothing is lost by reading only here. The score is printed arithmetic, not a verdict: 1×registers + 1.5×not-done-readiness-rows-touched + 2×dependent-suggestions (capped at 3) + 1×captured-observations. Effort does not divide the score - it breaks ties, so an expensive step that unblocks three gates outranks a cheap one that unblocks none. The readiness link is a shared-content-word match (≥4 words) and the matched row ids are shown, so a bad link can be rejected on sight.
Two kinds of row. owner rows cannot be closed by code: they wait on a licence, a budget, a reading of terms, or a definition. engineering rows can. The board is sorted by score across both kinds; the brief's own "start here" list on the first page takes the top row of each kind.
Why a consolidated board exists. Before this page the same object type lived in five machine-readable registers plus three HTML-only pages, using two id formats. The table below that collision is the first thing to fix, because it makes "adopt SG-05" ambiguous between two unrelated suggestions.
