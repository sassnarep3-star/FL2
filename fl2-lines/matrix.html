Matchup deficiency matrix

The trench and coverage mismatch view, and the exact reason it is empty rather than estimated.

This view is deliberately not populated. A 1st-to-4th string deficiency matrix needs a string-level rating per unit. No official league depth chart exists, the clubs' own charts put several players at rank 1 in the same slot, and this repository holds no per-game snap counts for 2026. Publishing cells built from jersey order would fabricate exactly the thing the brief says not to fabricate.
