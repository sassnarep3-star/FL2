1. Games whose book was withheld

Where two games resolved to byte-identical PDFs, the second game's rows were dropped rather than published. Publishing the other game's players under this game's id would be fabrication, so the cells are left empty and flagged instead.

3. The playtime table is captioned (Unofficial) by the league

The league prints Percent of playtime per player on offense, defense and special teams (Unofficial) above the table. It is the only official snap-count source that exists — nfl.com/stats/snap-counts/ returns 404 — so we use it and carry the label on all 14 affected games rather than dropping it.

4. A venue name disagrees with another section of this repo

Session arena/d81dd61b-fl2 recorded the NE @ DET venue as Munich / FC Bayern Munich Stadium, read from the game-centre page. The Game Book for the same fixture prints Allianz Arena, Munich, Germany on its header. Both are official league sources, so this is published as a discrepancy rather than silently reconciled: for anything that keys off the venue, the Game Book value should win, because it is the league's own game record rather than a fixture listing.

5. What this data cannot be used for

A Game Book is published only after a game kicks off. It is therefore never a pre-game input: it is the ground truth a pre-game model is scored against, and the historical corpus a depth model is fitted on. Any use of it as a same-week input would be look-ahead.
