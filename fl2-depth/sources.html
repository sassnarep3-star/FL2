How the capture works

The sandbox has no network route to nfl.com, so the capture runs in GitHub Actions, which does. The workflow fetches each game-centre page, follows the Download Game Book (PDF) link, hashes the bytes, converts to text with pdftotext -layout, parses it, and commits the CSVs. The PDFs themselves are never committed. The parser has an offline self-test built from synthetic books that reproduce the real column geometry, and the workflow fails if that test fails.
