Depth from playing time, not from a depth chart

The league's own per-club depth charts are captioned unofficial, and only 5 of 32 clubs publish them. So this section derives depth from the one source the league publishes for every game: the official NFL Game Book. Each book carries the actual starters, the official inactive list, and a playtime table with snap counts on offence, defence and special teams. Every row on this site links to the exact PDF it was parsed from, and each PDF is hashed.

What is on each page

Actual starters

11 offence and 11 defence per club, as printed in the book's Lineups block — the players who actually took the first snap, not a club's claimed order.

Snap counts & depth

Every player's snaps and share on offence, defence and special teams. This is the input for depth-from-playing-time, and it is how a backup's real workload is seen.

Inactive list

The official Not Active and Did Not Play lists, per club — so "not listed" and "available" are not silently treated as the same thing.

Sources & hashes

Every PDF URL with its SHA-256, the venue, roof and weather the book printed, and the league's copyright notice verbatim.

Questions

What still has to be answered before depth can be used in a model, and how each answer would be discovered.

Suggestions

Options for the next step, with the trade-off of each, so a reviewer picks a path before anything is built.

Two caveats travel with this data. First: the league captions its playtime table (Unofficial). That caption is stored on every snap row rather than dropped. Second: the Game Book is published only for games that have kicked off, so it can never be a pre-game input — it is the ground truth a pre-game model is checked against, and the historical corpus a depth model is fitted on.
