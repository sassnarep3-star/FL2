Originated lines

The closing market we must beat, with the checksum-verified base rates behind it.

Line origination is not yet published, and that is deliberate. We have a verified market baseline. We do not yet have a model that beats it. Publishing "our line" before it can be shown to differ from the close in a useful direction would be an unverified claim, so this page publishes the baseline it must beat instead.

Sign-convention validation (this caught a real bug)

Reading spread_line from the schedules file as a home-team line produces a 56.93% home cover rate, which is arithmetically impossible. Inverting the sign and validating against the outcome column that ships inside the closing-lines file fixes it.
