Team Metrics — Joined Dataset

Four official NFL.com tables joined into one auditable row per club, with cross-source arithmetic checks.

One row per club, joining four official NFL.com tables. This is the input layer for every rating, correlation and signal on the site.

Cross-source verification. Points per game computed as PF ÷ games from the standings was compared with NFL Next Gen Stats' independently published PPG. Where both exist (16 clubs), all 16 agreed to within 0.05 — pure one-decimal rounding. Completion percentage and yards per attempt were likewise recomputed from their own numerators and denominators; 32 of 32 matched. The build script fails loudly if any of these drift, so a bad transcription cannot slip through silently.

What this table cannot do

It has no opponent adjustment. A club that has played four games against the league's weakest defences will look efficient here and is not. Every serious rating model adjusts for opponent strength, and doing so requires game-level data — which opponent, which week — that this table does not carry. Treat these numbers as raw inputs, not as ratings.
