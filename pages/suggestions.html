Suggestions — Review Before Implementing

Every proposed improvement, with the problem it solves, its evidence, its cost and its risk — so a path can be chosen before any change is made.

This is the review surface the brief asked for. Nothing here has been implemented without being listed, and nothing should be implemented from this page without being chosen here first. Each row carries the problem it solves and the evidence behind it, so a path can be picked on merit rather than volume.

How to use this page. Read the problem column first. If a problem is not real to you, reject the suggestion. If it is real, the recommendation column says whether the fix is safe to adopt now, needs a test first, or should be rejected. 9 are adopt-now, 6 need a test or a decision from you.

Ranked by impact, then by how cheaply the risk can be retired. Effort and risk are qualitative on purpose — inventing a story-point estimate for research work would be a false precision.

Recommended path, in order

  1. Adopt the governance set now (SG02, SG03, SG07, SG08, SG13). All low effort, all reduce the chance of a costly mistake, none require a purchase. Together they make the leaderboard honest.
  2. Answer the spend question (Q15). SG05 — a licensed historical odds archive — is the highest-leverage action in the whole project. Nine of twelve strategies cannot be graded without it. It cannot be done without you.
  3. Then, and only then, start backtesting. With odds history and a pre-registered registry, a backtest is informative. Without them, it produces a number that looks like an answer.
  4. In parallel, close the depth-chart gap (SG09). It is mechanical work with no dependencies, and it completes a core requirement that is currently 2/32 done.

What was deliberately rejected

Not built: an automated bettor (SG13). Zero of twelve strategies pass the out-of-sample gate, so automating placement right now would convert modelling error into money at scale — and it would change the legal posture of the project. The site publishes lines; it does not stake them.
Not built: a live-odds display (Q16). Without rights confirmation (Q03) and a spend decision (Q15), republishing licensed prices would be a legal exposure taken for a cosmetic gain.
